## 🧑‍💻 Sobre mí

Soy desarrollador fullstack con experiencia construyendo sistemas reales: un **POS multi-sucursal en producción** para una empresa con múltiples franquicias y una **plataforma SaaS multi-tenant para clínicas de optometría**. Me especializo en React 19 + TypeScript en frontend y Express + Prisma en backend, con despliegues en Vercel, Render y Azure.

- 📍 México · Disponible para freelance y trabajo remoto
- 🎓 Estudiante de TIID en Universidad Tecnológica
- 🏗️ Enfocado en arquitectura limpia, sistemas escalables y código mantenible
- 🎯 Buscando proyectos donde el código resuelva problemas reales de negocio

## 🚀 Proyectos Destacados

### 🛒 [POS LYFRGL](https://github.com/yairolvera25-dev/POS_FMB) — Sistema de Punto de Venta Multi-Sucursal
> Sistema POS completo para cadena de franquicias con facturación electrónica (CFDI 4.0), gestión de inventario, módulo de clientes con datos fiscales y control de caja por sucursal.

**Stack:** React 19 · TypeScript · Express · Prisma · SQL Server · Azure · Vercel · Render  
**Deploy:** [pos-lyfrgl.vercel.app](https://pos-lyfrgl.vercel.app) · Backend: [pos-lyfrgl.onrender.com](https://pos-lyfrgl.onrender.com)

[![Repo](https://img.shields.io/badge/Ver_repositorio-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/yairolvera25-dev/POS_FMB)

---

### 👁️ [VisionCore](https://github.com/Canox02p/VisionCore) — SaaS Multi-tenant para Ópticas
> Plataforma SaaS con panel SuperAdmin, dashboards por rol (Admin, Optometrista, Recepcionista), módulo de reportes con exportación PDF/Excel, integración con Mercado Pago y auditoría completa de acciones.

**Stack:** React 19 · TypeScript · Express · Prisma · PostgreSQL · Docker  
**Arquitectura:** Multi-tenant · JWT Auth · Role-based access · Rate limiting

[![Repo](https://img.shields.io/badge/Ver_repositorio-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Canox02p/VisionCore)
